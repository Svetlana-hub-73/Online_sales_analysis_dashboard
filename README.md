# 📊 Online Sales Analysis Dashboard


Интерактивный дашборд для анализа продаж в интернет-магазине.  
С графиками, фильтрами, Excel-отчётами и автоматической генерацией презентаций PowerPoint — всё на базе Python + Streamlit.

## 🚀 Возможности

- 📊 Графики и визуализация: распределения, корреляции, barplot’ы
- 📂 Фильтрация по категориям и брендам
- 🧠 Аналитика рейтингов, продаж и стабильности брендов
- 📈 Автоматическая генерация презентации `.pptx`
- 📥 Выгрузка Excel-файлов

## ▶️ Как запустить локально

```bash
git clone https://github.com/ТВОЙ_НИК/НАЗВАНИЕ_РЕПО.git
cd НАЗВАНИЕ_РЕПО
pip install -r requirements.txt
streamlit run online_analysis.py


### 🚀 2. **Разворачиваем на Streamlit Cloud**

> Это супер-просто — всего 1 раз, дальше обновляется автоматически при `git push`.

#### 1. Перейди на [https://streamlit.io/cloud](https://streamlit.io/cloud)

#### 2. Нажми **"Sign in with GitHub"**

#### 3. Нажми **"New app"**

- Выбери репозиторий
- Выбери ветку `main`
- Укажи файл запуска: `online_analysis.py`
- Нажми **Deploy**

Через пару минут твой дашборд будет в онлайне!
